1.1 实验简介
本实验将引导读者完成Ascend C算子开发所需要的CANN环境配置。完成本实验后，开发者应可以熟练掌握CANN软件包
的安装过程，并可以扩展到其他昇腾相关任务中。
在进行 Ascend C 算子开发之前，通常需要先完成驱动固件和 CANN 软件包的安装，以实现开发环境的基本配置。考虑
到本实验默认在已完成昇腾 NPU 驱动固件部署的环境中进行，故不再提供驱动固件安装的具体步骤和示例。
下面将以操作系统架构X86_64、root用户操作为例，介绍CANN软件包安装的步骤。
1.2 实验要求
学习者需要在实验报告中详细记录每一步过程的安装反馈屏显，记录完整环境配置过程，

1.1.4 安装CMake
在进行 Ascend C 算子开发时，特别是在使用KernelLaunch 或 FrameworkLaunch调用算子的过程中，要求安装 CMake
工具。CMake 是一个跨平台的自动化构建系统，它支持多种编译器和编译环境，广泛用于大多数开源项目的构建与配置。在本
实验中，我们要求安装 CMake 版本 3.16 或更高 版本（适用于 Linux 系统，x86_64 架构）。
若系统尚未安装 CMake，或版本较低，学习者可以使用程序清单1-8中的指令手动下载并安装 CMake 3.16 版本。
程序清单1-8 安装CMake3.16
1. mkdir -p cmake-3.16 && wget -qO- "https://cmake.org/files/v3.16/cmake-3.16.0-linux-x86_64.tar.gz" | tar --
strip-components=1 -xz -C cmake-3.16
2. export PATH=`pwd`/cmake-3.16/bin:$PATH
下面对程序清单1-8中的指令进行简略说明。
· mkdir -p cmake-3.16：创建一个名为 cmake-3.16 的目录，用于存放 CMake 的安装文件。
· wget -qO-：通过 wget 从 CMake 官方网站下载 cmake-3.16.0-linux-x86_64.tar.gz 压缩包，并使用 -qO- 将其内容直接输
出到标准输出。
· tar --strip-components=1 -xz -C cmake-3.16：使用 tar 命令解压下载的文件，并将其解压到 cmake-3.16 目录中。--
strip-components=1 选项用于去除解压路径中的第一层目录，使文件结构更简洁。
· **export PATH=\pwd`/cmake-3.16/bin:$PATH**：将解压后的 cmake-3.16/bin` 目录加入系统的 PATH 环境变量中，使其
成为当前会话的可执行命令。
执行上述命令后，您可以使用程序清单1-9中的命令验证 CMake 是否成功安装。
程序清单1-9 验证CMake是否安装成功
1. cmake --version
